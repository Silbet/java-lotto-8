# java-lotto-precourse
## 로또

무작위로 발행되는 로또를 원하는 만큼 구매하고, 당첨 번호와 보너스 번호를 입력하면 **당첨 내역**과 **수익률**을 출력하는 프로그램 입니다.

## 실행 방법

1. 구입 금액을 1,000원 단위로 입력한다. (1장 당 1,000원)
2. 당첨 번호를 쉼표를 기준으로 6개 입력한다. (e.g. 1,2,3,4,5,6)
3. 보너스 번호 1개를 입력한다.
4. 프로그램이 구매한 로또 번호와 당첨 결과, 수익률을 출력해준다.

## 기능 목록

### 주요 기능

1. **당첨 번호 발행**
    - 입력 받은 금액 만큼 무작위로 당첨 번호 6개를 뽑는다.
2. **당첨 결과 계산**
    - 발행된 로또 번호와 사용자가 입력한 당첨 번호를 비교해 등수를 계산한다.
    - 2등은 보너스 번호 일치 여부로 결정된다.
3. **수익률 계산**
    - 구매에 사용한 금액과 당첨 내역을 비교해 수익률을 계산한다.
4. **예외 발생 시 재입력**
    - 사용자가 잘못된 값을 입력할 경우 에러 메세지를 출력 후 그 부분부터 입력을 다시 받는다.

### 입력

1. **로또 구입 금액 입력하기**
    - 1,000 단위로 숫자를 입력한다.
    - [예외] 정수가 아닌 경우
    - [예외] 0 이하 값인 경우
    - [예외] 1,000으로 나누어 떨어지지 않는 경우
2. **당첨 번호 입력하기**
    - 당첨 번호 6개를 입력한다.
    - 번호는 쉼표를 기준으로 구분한다.
    - [예외] 정수가 아닌 경우
    - [예외] 1~45 사이의 값이 아닌 경우
    - [예외] 번호가 6개가 아닌 경우
    - [예외] 번호가 중복되는 경우
3. **보너스 번호 입력하기**
    - 보너스 번호 1개를 입력한다.
    - [예외] 정수가 아닌 경우
    - [예외] 1~45 사이의 값이 아닌 경우
    - [예외] 번호가 1개가 아닌 경우
    - [예외] 번호가 당첨 번호와 중복되는 경우

### 출력

1. **발행한 로또 수량 및 번호 출력하기**
2. **당첨 내역 출력하기**
3. **수익률 출력하기**
    - 수익률은 소수점 둘째 자리에서 반올림한다.
4. **ERROR 메세지 출력하기**
    - 예외 상황 시 에러 문구를 출력한다.
    - 에러 문구는 "[ERROR]"로 시작해야 한다.
